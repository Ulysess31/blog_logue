# Project instructions

Before making changes in this repository, read [`memory-bank/architecture.md`](memory-bank/architecture.md) to understand the current structure, application flow, and configuration constraints. Keep that document accurate when architectural responsibilities or project structure change.

Prefer the existing Next.js App Router, TypeScript, Tailwind CSS, and shared utilities/components. Keep browser-only behavior in client components, and avoid introducing server services or persistence without a project requirement.
